# Thought Museum

Thought Museum is an application designed to facilitate the creation and preservation of thoughts and ideas in an organized manner.

## Table of Contents
- [Application Structure](#application-structure)
- [Features](#features)
- [Usage Instructions](#usage-instructions)

## Application Structure

- **cli2.py**: A Command Line Interface (CLI) implementation that allows users to interact with the Thought Museum through terminal commands.
- **my_app.py**: A Graphical User Interface (GUI) implementation that provides a user-friendly way to interact with the application.

## Features

- **Thought Creation**: Users can create new thoughts and save them to the museum.
- **Organized Storage**: Thoughts are stored in an organized way, making retrieval efficient.
- **Search Functionality**: Users can search for thoughts based on keywords.
- **Export Options**: Thoughts can be exported in various formats for sharing and backup.

## Usage Instructions
### CLI Usage
To interact with the Thought Museum using the CLI:
1. Open a terminal window.
2. Navigate to the directory containing `cli2.py`.
3. Use the following command to create a new thought:
   ```bash
   python cli2.py new "Your thought here"
   ```
4. To view all thoughts, use:
   ```bash
   python cli2.py list
   ```

### GUI Usage
To use the Thought Museum using the GUI:
1. Run the `my_app.py` script:
   ```bash
   python my_app.py
   ```
2. Use the GUI to create, view, and manage your thoughts interactively.
